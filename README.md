# statistics-skill-creator
This projects helps people create SKILL.md for their statistical projects.
This skill creator follows specific procedure, for any statistical tasks: it asks for the references that supports the tasks, verifies inputs, undergoes exploratory data analysis, checks assumptions, and finally generate reports.

This skill creator is flexible as it is able to deal with any kinds of tasks and accpets user inputs during the creation process. It is strutural in the sense that for any skills to be created, it goes through specific procdure and holds certain templates. This creator is user friendly and beginner friendly, as it is able to provide sugggestions based on standardized textbooks, but is open to new methodologies, textbooks, as long as provided.
